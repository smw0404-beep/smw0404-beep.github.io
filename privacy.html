개인정보처리방침

시행일: 2026-10-23

1. 수집하는 정보

youtube-weekly-report(이하 "도구")는 사용자가 Google 계정으로 직접 허용한 경우에만 아래 정보를 읽기 전용으로 가져옵니다.

  • YouTube 계정 보기(youtube.readonly): 채널 이름, 업로드한 영상 목록·제목·게시일
  • YouTube 분석 보고서 조회(yt-analytics.readonly): 조회수, 시청 시간, 시청 지속률, 유입 경로 등 채널 분석 지표

2. 이용 목적

채널 운영자 본인이 자기 채널의 영상 성과를 점검하고 개선 방향을 정하는 데에만 사용합니다.

3. 보관과 공유

  • 가져온 데이터와 로그인 토큰은 운영자 본인의 컴퓨터에만 저장됩니다.
  • 제3자에게 판매·제공·공유하지 않으며, 광고에 사용하지 않습니다.
  • Google API 서비스에서 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

4. 권한 철회

언제든지 Google 계정 → 서드파티 액세스에서 이 도구의 접근 권한을 삭제할 수 있습니다. 삭제하면 이후 데이터를 가져오지 않습니다.

5. 문의

YouTube 명우 채널을 통해 문의할 수 있습니다.

Privacy Policy (English)

This tool reads, with read-only access and only after the account owner grants permission, YouTube channel information (youtube.readonly) and YouTube Analytics reports (yt-analytics.readonly). It is used solely by the channel owner to review their own channel performance. Data and tokens are stored only on the owner's computer and are never sold, shared or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
